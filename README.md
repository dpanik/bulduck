# BULDAK HOT CLUB

Одностраничная независимая демо-концепция магазина корейской лапши в anime / Japanese pop стиле.

## Запуск

Из папки проекта:

```powershell
npm install
npm run dev
```

http://localhost:3008

Для production: `npm run build`, затем `npm start`.

## Публикация

Сайт настроен как статический экспорт Next.js для GitHub Pages:

https://dpanik.github.io/bulduck/

При push в ветку `main` GitHub Actions собирает проект и публикует папку `out`.

## Стек

Next.js 16, React 19, TypeScript, GSAP + ScrollTrigger, CSS. Локальные шрифты Unbounded и Golos Text. Оптимизированные WebP. Без тяжёлых 3D-библиотек.

## Где менять

- `app/page.tsx`: секции, CTA, логика корзины и промокода, тексты hero и акции.
- `app/content.ts`: товары, цены, условная острота, описания, примеры отзывов.
- `app/globals.css`: цвета, композиция, адаптивность, все CSS-анимации.
- `app/layout.tsx`: SEO и Open Graph.
- `public/mascots.webp`: иллюстрация двух взрослых anime-маскотов; исходник `mascots.png`.
- `public/carbonara.webp`, `original.webp`, `cheese.webp`, `2x.webp`: упаковки.
- `ART-DIRECTION.md`: точный промпт image_gen и источники.
- `output/playwright/`: сценарии проверок и скриншоты.

Промокод HOT15 даёт 15% на корзину, скидка округляется до рубля. Микс добавляет по упаковке каждого вкуса к текущей корзине. Цена микса в CTA сейчас задана в `page.tsx`; при изменении цен обновите и её. Корзина хранится в localStorage, максимум 99 каждого вкуса. При нулевом количестве позиция удаляется.

## Демонстрационные данные

Цены, акция и отзывы вымышлены и отмечены на странице. Оформление не отправляет заказ и не списывает деньги. Для реальной торговли нужны данные продавца, доставка, сервер заказов и платёжная интеграция. Маскоты созданы для этой концепции, не являются официальными персонажами бренда.

## Анимации и доступность

GSAP reveal, scroll parallax, движение иллюстрации, летящие искры, бегущая строка, плавное появление и наклон карточек, плавающие упаковки в акции, hover CTA, уведомления корзины. В footer есть выключатель движения. Учитывается prefers-reduced-motion. Диалог использует нативный focus trap, закрывается Escape, восстанавливает фокус. Меню и корзина доступны с клавиатуры.

## Проверки

Production build и TypeScript проходят. Chromium: 375×812, 768×1024, 1024×768, 1440×960, 812×375 — горизонтального переполнения нет. Проверены фильтры, добавление и изменение количества, ошибочный промокод, HOT15, демо-оформление, Escape, сохранение корзины после reload, микс, мобильное меню и reduced motion. Ошибок JavaScript в проверочном сценарии нет.
